# ADR 0010: Colour enum kept; public labels updated

Status: Accepted (18 Oct 2026, plan §App spec)

## Decision
Colour identifiers (LIME, ORANGE, RED, BLUE, GREY) are unchanged; labels become Available Now and Permanently Employed. Colour is derived and never auto-green.

## Why
Avoids a breaking API change (/api/v1 compatibility) while matching the spec wording.

## Trade-offs / open items
Amber/Red public label naming is unconfirmed; palette is Q12.
